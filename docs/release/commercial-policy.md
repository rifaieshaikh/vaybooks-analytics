# Commercial policy

Date: 2026-10-07

This is the sales offer. The application shows these rules on Settings → Plan and support.

- Plan: desktop. Wholesale and retail packs are enabled.
- Price: included with this install. The application does not charge a separate subscription.
- Support: the contact in `VAY_SUPPORT_CONTACT`. No response time is promised. If the contact is empty, Settings says that none is configured.
- Deployment: the desktop install and its default organization. Hosted mode is not this offer.
- Trial: none. A desktop install is active when the application opens.
- Renewal: no renewal date.
- Expiry: no expiry date. On a hosted install, a pack stays available only while its entitlement is on. Turning a pack off keeps customer rows and does not widen another user's permissions.

`support_gate` remains the support-hours trend check. It is not the license screen.
